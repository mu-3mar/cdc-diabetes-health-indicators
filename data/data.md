# Dataset

## Overview

This project uses the **Diabetes Health Indicators Dataset**, which contains health-related information collected through the Behavioral Risk Factor Surveillance System (BRFSS).

The dataset is publicly available on Kaggle and can be downloaded directly from the source below.

## Dataset Source

**[Diabetes Health Indicators Dataset – Kaggle](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset)**

## Dataset Access & Setup

The dataset files are not included in this repository. To obtain the data and reproduce the project results, follow these steps:

1. Visit the Kaggle dataset page using the link above.
2. Download the dataset files.
3. Extract the downloaded files if necessary.
4. Place the required CSV file inside this directory (`Data/`).

After downloading, the directory structure should look like this:

```text
project/
│
├── Data/
│   ├── README.md
│   └── diabetes_012_health_indicators_BRFSS2015.csv
│
├── notebooks/
├── src/
└── README.md
```

## Notes

- The dataset is publicly available on Kaggle.
- Dataset files are intentionally excluded from this repository to keep the repository lightweight.
- Make sure the downloaded file name and directory path match the ones expected by the project notebooks and scripts.
