# Data

The dataset is **not** committed to this repository — `data/raw/` and `data/processed/` are excluded in [.gitignore](../.gitignore).

## Download

**https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset**

Download it and place the file `diabetes_binary_health_indicators_BRFSS2015.csv` at:

```text
data/raw/diabetes_binary_health_indicators_BRFSS2015.csv
```

That is the only file you need. It contains 253,680 rows × 22 columns and is the input for [`notebooks/01_initial_exploration.ipynb`](../notebooks/01_initial_exploration.ipynb).

## Expected layout

```text
data/
├── README.md                                       # this file
├── raw/
│   └── diabetes_binary_health_indicators_BRFSS2015.csv   # download from the link above
└── processed/                                      # generated by the notebooks
    ├── diabetes_cleaned.csv                        # notebooks/02_data_cleaning.ipynb
    └── prepared/
        ├── X_train.csv
        ├── X_test.csv
        ├── y_train.csv
        └── y_test.csv                            # notebooks/06_feature_engineering_preparation.ipynb
```

Everything under `processed/` is produced by running the notebooks in order; it does not need to be downloaded.

## Provenance

The Kaggle dataset above republishes the **CDC Diabetes Health Indicators** (BRFSS 2015), also distributed by the UCI Machine Learning Repository (dataset ID 891, DOI `10.24432/C53919`). Check the terms of the source you download from before redistributing the data — this repository includes no licence statement for it.
